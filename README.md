# Sinthu Jeeva Portfolio

A responsive GitHub Pages portfolio built as a static HTML/CSS/JavaScript site.

## Publish at `https://sinthuja-j.github.io/Portfolio/`

1. On GitHub, create a **public** repository named `Portfolio`.
2. Upload everything in this folder to the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/`
   - `Sinthu_Jeeva_Resume.pdf`
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Once GitHub Pages is enabled, the site will be available at:
   `https://sinthuja-j.github.io/Portfolio/`
7. Add that URL to the **Featured** section or **Contact info → Website** on LinkedIn.

## Easy edits

Most content is directly inside `index.html`.

- Change the headline in the `hero` section.
- Replace the email address in the contact links if desired.
- Add/remove projects inside `.projects-grid`.
- Replace `Sinthu_Jeeva_Resume.pdf` with a newer resume using the same filename so the links continue to work.

## Notes

- The page uses the public GitHub profile image endpoint only if you choose to add it later; no image is required for the current design.
- Phone number is intentionally not displayed publicly.
- The site includes dark/light mode, responsive navigation, animated stats, project filters, SEO metadata, and a resume download link.
